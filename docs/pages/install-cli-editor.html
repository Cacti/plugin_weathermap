About the former standalone editor

Older manuals described a separate editor.php and editor-config.php. Those are not the integrated editor entry points supplied by this Cacti-maintained 2.0 bundle.

Use the Cacti editor, which uses Cacti authentication and permissions. Do not expose an old standalone editor from a previous release alongside it. For scripted rendering, see command-line use. The original separate project has its own distribution and documentation.
