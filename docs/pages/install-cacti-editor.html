Enabling the Cacti map editor

The 2.0 editor is part of the integrated Cacti plugin. There is no separate editor.php installation or editor-config.php setup.

  1. Complete plugin installation.
  2. Grant management access through Cacti, then review map permissions.
  3. Give the web service account the configuration and optional image-library permissions described in the installation guide.
  4. Open a map using Edit Map. Add a test node, save, reopen and confirm the change. Test Undo/Redo, then verify poller-generated viewer output separately.

Use the editor guide for the current controls. The troubleshooting guide covers denied access, failed saves and blank output.
