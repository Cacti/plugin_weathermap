Troubleshooting and common questions

Start with the WEATHERMAP messages in Cacti's log and the timestamp on the map. A saved editor change, a newly rendered map and an updated Cacti graph happen at different stages. Checking which one has stopped updating will help narrow down the problem.

The viewer is blank or stale

Check registration, active status, map permissions, rendering interval and the poller log. Confirm the poller can read the configuration, images/fonts and RRDs and write output. A successful editor save does not force a poller run. Check that the browser is showing the intended map and installation.

There are no Weathermap log messages

Confirm the plugin is installed/enabled and the Cacti poller is running. Check whether rendering is disabled or scheduled less frequently. Enable the plugin Debug Mode temporarily when needed, reproduce one cycle, then restore the setting to avoid unnecessary log volume.

Changes do not save or selection does not apply

In a properties dialog, select a candidate then click Use interface/Add/Replace as appropriate, followed by Save. Cancel discards dialog edits. Check errors, destination-directory write permissions and concurrent changes in other tabs. Refresh and reopen the object to verify the saved result. Do not repeatedly overwrite a map someone else is editing.

An interface is missing from search

Use a shorter phrase from the device/data-source name, interface index or description. Browse all and use Next/Previous results; only up to 100 matches are returned per page. Confirm graph permissions and that Cacti has created the interface graph and data source. The interface picker uses the standard interface query; an arbitrary graph template is not necessarily an assignable traffic interface. Identical graph titles need clearer names in Cacti.

Hover graphs are missing or show the wrong data

Confirm the map has the intended OVERLIBGRAPH URL and the viewer account can open that Cacti graph directly. Graph IDs and data-source IDs are different. Traffic sources set the map reading; preview URLs set images. If a wrong preview remains, inspect main versus additional preview separately. A CPU preview does not replace traffic measurements. Custom or remote preview URLs depend on their target server and authentication.

A hover popup is too wide or goes off screen

The current viewer fits previews to the browser window. First check the graph URL's graph_width and graph_height, and try the popup at normal browser zoom. A custom image can have very different dimensions from a Cacti graph.

The older OVERLIBWIDTH and OVERLIBHEIGHT directives are still recognised. They supply size hints; they do not request a different graph from Cacti. Change the image URL or hover defaults to change the graph itself.

Values are eight times too large, or utilisation is wrong

Ordinary RRD traffic values are bytes/sec and are converted to bits/sec. Use gauge: for values that should not receive that conversion, such as percentage CPU. Check DS names, first-endpoint direction, capacity, aggregation and any scale factors. 1G equals 1000M with KILO 1000. An Errors graph is not a traffic graph. See the data-source guide.

A traffic spike is visible now but absent from a preview

Map snapshots and graphs may cover different timestamps or consolidation intervals. Compare the map's render time with graph time range, resolution and cache/Boost state. Refresh the full Cacti graph and compare the same period before concluding that the measurement is lost. Sharper preview images do not create additional historical samples.

Undo/Redo is unavailable or refuses a restore

Close the dialog first. Only the last two saved changes in that map/tab/session are available. A new edit after Undo clears Redo; concurrent map or dependency changes invalidate old snapshots. Check writable private PHP temporary storage and browser tab-coordination support. Storage limits retain up to eight histories and 8 MiB per authenticated session; inactive histories expire after four hours. Image uploads and configuration-file deletion are not covered.

History uses the browser's Web Locks API, with a SharedWorker fallback, to coordinate tabs safely. If neither is available, the editor disables history while keeping normal editing available. Check browser support and the page's secure context when both buttons remain unavailable after a successful edit.

Curved comments remain straight

Use a TrueType comment font and enable Follow link curve in Map Style. Via Style determines the route separately. Text uses straight fallback for unsafe bends or insufficient space. Move the comment percentage, shorten it or adjust the route. Bitmap fonts cannot provide the same curved glyph rendering.

Uploading or deleting an image fails

Use PNG/JPEG/GIF within 5 MB and four million pixels; PHP/web-server limits can be lower. Check the library directory permissions. Referenced images cannot be deleted, including references found through includes. Remove assignments first. SVG uploads and symlink management are not supported by the image form.

Rendering fails, fonts are missing or labels are unreadable

Check GD image-format support, FreeType, font file paths and PHP memory limits in the actual rendering environment. Large canvases and images need more memory. Web PHP and poller CLI PHP can differ. Review logs for the concrete error rather than applying old Debian/PHP 4 workarounds. Cacti themes style the UI; map colours and fonts are configured separately.

A data-source dependency is unavailable

Check the selected source's requirements: local RRD access/RRDtool, PHP SNMP, fping or a Cacti integration. Do not install an unrelated PHP module just because an old manual says so. Read the exact source warning and confirm whether the dependency exists under the poller account.

A PHP function or class is missing

Confirm the installed plugin files belong to one consistent release and that Cacti/PHP versions meet requirements. Verify required extensions under both PHP environments. Do not copy random older libraries into the plugin to silence the error.

Can a logo or other image appear without a link?

Yes. Use a node with an icon and no connected links; omit its label if unnecessary. Upload the image through Manage Images and assign it in Node Properties. A background is more suitable when the image should define the canvas backdrop.

How do I bend a link around other objects?

Open Link Properties and choose Via, then click the canvas to place a bend. Via Style chooses a curved or angled route. In raw configuration, each VIA adds a point along the route:

LINK uplink
 NODES router switch
 VIA 200 100
 VIA 360 100

The endpoints must already exist. Moving a comment along a link changes its text position; it does not add a bend.

Two links between the same nodes overlap

Give each link its own via point so the paths pass on different sides. For more control, use endpoint offsets in NODES; the reference includes pictures and examples of parallel links. Each link keeps its own traffic source, capacity and graph URLs.

If you want one arrow showing the total instead, use combined traffic sources. That changes what is measured, rather than just separating the lines visually.

Combining sources did not combine the graphs

This is expected: TARGET sums readings separately for IN and OUT, while INFOURL and OVERLIBGRAPH remain independent. Create a matching aggregate graph in Cacti if you want a historical total, then configure its URLs. Separate links are often clearer for main/backup circuits.

A setting is not exposed by the form

Use Edit Raw Configuration and the configuration reference for supported expert options. Report missing workflows or unclear labels to the Cacti plugin issue tracker with a concrete example; older claims that the editor cannot upload images, edit colours or work with curves no longer apply.

Timestamp timezone or locale looks wrong

Compare the PHP timezone and locale used by the poller with those used by web PHP. The renderer uses Intl-based strftime-style formatting for timestamps. A timezone name in a time: target is separate from the server timezone. Use a valid PHP timezone identifier and check the displayed map timestamp after rendering.

Report a reproducible problem

Include Cacti, Weathermap, PHP and RRDtool versions, browser/theme, exact steps, expected/actual results and relevant log lines. Identify release tag versus develop commit. Provide a minimal sanitised map when practical. Remove community strings, passwords, tokens and private addresses before posting publicly.
