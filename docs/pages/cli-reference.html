Command-line reference

The legacy wrapper's accepted options below are taken from its actual option parser. Run it from the plugin directory inside Cacti; see requirements and limitations. The default RRDtool path in the wrapper is /usr/bin/rrdtool; verify it for your installation.

cd /path/to/cacti/plugins/weathermap
php weathermap --config configs/example.conf --output /tmp/example.png --htmloutput /tmp/example.html
Option Use
--config=FILE Read a map configuration; default weathermap.conf.
--output=FILE Choose the image output path; configured output/default applies when omitted.
--htmloutput=FILE Write an accompanying HTML page.
--image-uri=URI Override the image URI referenced by generated HTML.
--define=NAME=VALUE Set a map hint for this run, equivalent to a global SET.
--debug / --uberdebug Enable diagnostics; uberdebug removes normal debug suppression.
--stats Print collected processing statistics.
--dumpafter Dump internal map state for diagnosis; output may be large and include sensitive configuration.
--dumpconfig=FILE Serialize the loaded configuration to another file. Back up first and inspect changes; do not overwrite the source casually.
--sizedebug / --no-data Skip live data reading. Both options use the same branch in this wrapper; they are useful for checking layout without polling sources.
--randomdata Generate random example readings; not monitoring data.
--bulge Enable width modulation for the run.
--no-warn=CODE,CODE Suppress selected warning codes, for example WMWARNxx. Correct real faults before suppressing warnings.
--help / --version Show usage or the wrapper version string. Some legacy wrapper text can lag the plugin INFO version.

Output and permissions

Run under an account with the required read/write access. Configuration may specify IMAGEOUTPUTFILE, HTMLOUTPUTFILE and HTMLSTYLE; command-line overrides are useful for isolated tests. Do not run a second periodic rendering job alongside ordinary Cacti polling without coordinating schedules.

HTMLSTYLE static produces an image map with click links. HTMLSTYLE overlib also emits hover metadata. The integrated Cacti viewer supplies the JavaScript that displays those previews. The legacy command-line HTML wrapper still references overlib.js, which is no longer bundled, so its exported page is not a complete standalone hover viewer. Use the Cacti viewer for supported interactive maps; changing HTMLSTYLE alone does not make an exported page equivalent.
