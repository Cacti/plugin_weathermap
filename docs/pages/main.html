Getting started

Weathermap turns monitored data into a diagram: nodes identify places or devices; links show direction, traffic and utilisation. Cacti collects the data and generates historical graphs. Weathermap presents an overview alongside those graphs.

Before you begin

Use Cacti 1.2.29 or later and the PHP environment required by your Cacti version, with GD image support. The poller and web server may use different PHP configurations. See installation and upgrading before changing an existing system.

This is the Cacti-maintained fork. The separate Howard Jones project and its older releases have different compatibility requirements.

Create a traffic map

  1. Open Weathermap management with an account allowed to manage maps. Click the + at the right of the green Weather Maps heading. Create a configuration with a filename and title, then use the + beside that file to register it. Back on the management page, click the map title to open its editor. See the illustrated create-and-register walkthrough for each step.
  2. Choose Add Node, then click its position on the canvas. Set a display name and icon. Add the second endpoint.
  3. Choose Add Link, then click the first and second node. The first node defines the reference direction for IN and OUT.
  4. Open the link properties. Search for the traffic interface by device, port or description. Select a result, then click Use interface. Selection alone does not apply it.
  5. Set the link capacity, for example 1G or 500M into the first node and 200M out. Choose Same As 'In' when both capacities are equal.
  6. Save. Check the map in the viewer after its next render, and confirm the selected Cacti graph is the intended interface.

The editor saves individual actions; there is no final whole-map Save button. Dialog changes require their Save button. Viewer traffic changes when the map is generated, not continuously as packets pass.

How to read a map

Element Meaning
Nodes An icon or label at a map coordinate. A node can also represent a device measurement such as CPU, memory or host status.
Links Directional arrows between nodes. The measured values come from TARGET sources; capacity determines the utilisation percentage.
Colour scale Maps utilisation or another numeric value to a colour. A warm colour does not by itself prove a device fault; inspect the configured scale and capacity.
Comments Descriptive IN/OUT text, such as a circuit name or capacity. These are separate from the numeric utilisation labels.
Hover and click Hover previews and click destinations show historical graphs or pages. They are separate from the measurement used to colour the map.

Directions, units and capacity

IN means traffic into the first node in NODES first second; OUT means traffic out of that node. Verify direction against the corresponding Cacti interface graph. A reversed endpoint order can make a correct reading look backwards.

BANDWIDTH is capacity in bits per second. With the default KILO 1000, 1G equals 1000M. K, M, G and T are supported. If a custom map changes KILO, the conversion changes too. New implicit link capacities are 1000M in each direction; explicitly configured values are preserved.

A 200M reading on a 1G link is 20%. Adding a CPU preview does not change that reading. Adding another measured traffic source does; see combining sources.

A small configuration example

This example uses fixed values, so it needs no live interface. It illustrates the format rather than providing a production monitoring configuration.

WIDTH 800
HEIGHT 450
TITLE Demonstration network
KILO 1000
KEYPOS 20 330 Traffic utilisation
SCALE DEFAULT 0 50 0 180 0
SCALE DEFAULT 50 80 255 180 0
SCALE DEFAULT 80 100 220 0 0

NODE router
 LABEL Router
 POSITION 180 180
NODE switch
 LABEL Switch

LINK uplink
 NODES router switch
 BANDWIDTH 1G
 TARGET static:200M:100M
 OUTCOMMENT Example uplink

For a live map, use the interface picker to insert your actual RRD source and graph URLs. Do not copy graph IDs or RRD filenames from someone else's installation.

Access and safe administration

Cacti authentication, plugin realms and map permissions govern the integrated plugin. Viewing a map does not grant permission to manage it or view every graph referenced by it. Grant management only to trusted users: raw map syntax and advanced data sources can refer to server files and external resources.

Use the normal Cacti login and permissions; do not expose old standalone editor scripts or install an extra Plugin Architecture package. Keep backups outside the web root, follow Cacti's web-server guidance, and avoid world-writable configuration or image directories. The external-script data source is disabled in the bundle.

Help and reporting problems

Read troubleshooting and the error-code reference. Report reproducible problems to the Cacti Weathermap issue tracker, or ask on the Cacti forums. Include versions, relevant WEATHERMAP log messages and a minimal configuration with credentials and private details removed.
