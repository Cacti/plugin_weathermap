Command-line use in a Cacti installation

The bundled weathermap wrapper loads Cacti's include/cli_check.php using a relative path and imports PEAR Console/Getopt. It is not a self-contained modern installation package. Keep it in the Cacti plugin directory and run from there.

For normal production generation, use the Cacti poller. To rebuild registered maps, use php weathermap-cacti-rebuild.php under the poller account. See rendering.

For a one-off map, check wrapper dependencies and the configured RRDtool path first, then use the command-line reference. Use explicit output paths and avoid overwriting a registered map's output. A standalone-style generated page does not add Cacti map access control to a publicly served file.
